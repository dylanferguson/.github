# .github

Default community health files for my repositories. GitHub uses these for any repository that does not have its own.

## Pull request template

[`.github/pull_request_template.md`](.github/pull_request_template.md) is one line. Source: [Brandur on X](https://x.com/brandur/status/2111820383963795831).

> The only `.github/pull_request_template.md` you need. Less (an empty file) is also good. More is too much.
>
> I wish I'd saved a screenshot of the templates at Stripe and Snowflake. Dostoevsky-length volumes full of context no one read and nanny-ism that was universally ignored.
